# Publicar Mi Recetario en GitHub Pages

1. En GitHub, crea un repositorio **público** llamado `mi-recetario` en la cuenta `fucolin`.
2. En el repositorio, selecciona **Add file → Upload files**.
3. Descomprime este ZIP y sube **todos los archivos directamente a la raíz** del repositorio, incluido `index.html` y `.nojekyll`. Confirma con **Commit changes**.
4. Ve a **Settings → Pages**.
5. En **Build and deployment**, elige **Deploy from a branch**, rama **main**, carpeta **/(root)**, y guarda.
6. Cuando GitHub termine la publicación, abre https://fucolin.github.io/mi-recetario/

URL de prueba para Samsung Food:
https://fucolin.github.io/mi-recetario/lentejas-calabaza-espinacas-300g.html

**Importante:** Las URLs no funcionarán hasta que publiques el repositorio. GitHub Pages es público: las recetas serán visibles para cualquiera que tenga el enlace.
