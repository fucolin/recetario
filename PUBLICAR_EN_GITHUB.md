# Publicar Mi Recetario en GitHub Pages

1. Entra en el repositorio existente [`fucolin/recetario`](https://github.com/fucolin/recetario).
2. Selecciona **Add file → Upload files**.
3. Descomprime el ZIP y arrastra **todo el contenido de la carpeta `recetario`**, incluida la carpeta `images`, directamente a la raíz del repositorio.
4. Comprueba que GitHub muestre los archivos como añadidos o reemplazados y confirma con **Commit changes**. Puedes usar el mensaje `Añadir imágenes y enlaces a PDF`.
5. No cambies la configuración de Pages si ya está activa. Si necesitas revisarla: **Settings → Pages → Deploy from a branch → main → /(root)**.
6. Cuando finalice la publicación, abre https://fucolin.github.io/recetario/ y recarga la página.

URL de prueba para Samsung Food:
https://fucolin.github.io/recetario/lentejas-calabaza-espinacas-300g.html

**Importante:** Las URLs no funcionarán hasta que publiques el repositorio. GitHub Pages es público: las recetas serán visibles para cualquiera que tenga el enlace.
